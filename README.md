# 🎓 KymetraAI

An AI-powered multilingual education assistant built for Telegram.

KymetraAI helps students learn more effectively by answering questions, explaining concepts, generating quizzes, creating flashcards, solving academic problems, and supporting multiple languages using modern AI.

## ✨ Features

- 🤖 AI-powered learning assistant
- 📚 Subject explanations
- 📝 Quiz generation
- 🃏 Flashcards
- 🌍 Multi-language support
- 📈 Learning progress tracking
- 💬 Telegram interface
- 🔒 Secure environment variable support

## 🛠 Tech Stack

- Python
- python-telegram-bot
- Google Gemini AI
- SQLite
- Replit
- GitHub
